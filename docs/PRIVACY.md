# Privacy

What Developer Island reads, what it stores and what leaves your PC. The short version is in the [README](../README.md#privacy).

**Local-first. Developer Island never uploads your prompts or code.** (The AI tools themselves talk to their providers as usual; Developer Island only reads what they leave on your disk.)

- No accounts, telemetry or cloud sync. The only network traffic is what you set up: the calendar links you add, the GitHub CLI's read-only requests to GitHub when the GitHub module is on and `gh` is signed in, the file copies to your Home Cloud target folder when you drop files, and the update check if you turn it on.
- **Update check** (Settings, General, "Check for updates"; off until you agree, the island asks once). It is the one network request the app makes of its own: at most once a day (the first a short while after the app starts, again after an hour if GitHub could not be reached) and when you click "Check now", an anonymous `GET https://api.github.com/repos/maximilian467/Developer-Island/releases/latest`. It sends a `User-Agent: DeveloperIsland/<version>` header and the standard headers of any HTTPS request; GitHub sees your IP address as with any web request. No token, account, device id or usage data is sent. The answer is compared with the running version; `update-state.json` keeps the time of the last check and the newest release found (version, release page, file names and download links). Failures are logged by error type only. Clicking **Install now** downloads the setup, `SHA256SUMS-<version>.txt` and its `.sig` from the same release into `%LOCALAPPDATA%\DeveloperIsland\updates` (replaced by the next update), verifies them and runs the setup silently. Nothing is downloaded or installed without that click.
- The app reads local JSONL files that can also contain conversation content, but extracts only usage and session metadata: token counts, model, timestamps, session IDs and the working directory. It does not retain, display, log or upload prompt, message or code content.
- The local database (`%LOCALAPPDATA%\DeveloperIsland\usage.db`) contains token counts, model names, timestamps, session IDs, project folder names, daily totals and focus sessions.
- `settings.json` holds your settings, including repository paths, favorites, the auto-hide app list and the island's monitor (its Windows device name and hardware id); `tasks.json` holds your tasks; `ui-state.json` remembers the module you opened last. Private calendar links are kept in Windows Credential Manager and appear in settings only as "Google Calendar" or similar. Calendar event titles are kept in memory only.
- Camera and microphone marks read Windows' own record of which apps use those devices (the capability consent store in the registry, as Windows' privacy indicator does). Only "in use or not" is kept; app names are never stored, shown or logged, and nothing is recorded.
- **Awake** changes one system setting during a session: the lid-close action of the active power plan, set to "Do nothing" and put back at the end. `awake-session.json` holds the session's start, end and the original values until they are restored. For a timed session, a one-time task named "DeveloperIsland Awake Restore" in your Task Scheduler puts the value back at the end if the app is not running; it runs as you, without elevation, and is removed afterwards.
- `claude-plan.json` holds the last Claude plan percentages and reset times that Claude Code handed over, nothing else from its status line input (no paths, model, cost or session).
- **WhisperFlow dictation** (off by default) reads WhisperFlow's status file, `%LOCALAPPDATA%\WhisperFlow\status.json`, which holds only its state (recording, transcribing, done, ...), the time and its process ID; no audio, no text. Developer Island never writes to it and keeps nothing from it. Switched off, the file is not read.
- **Home Cloud** copies the files you drop onto the island, and only those, to the folder in `HomeCloudTargetPath`, normally a share on your own server. There is no cloud service and no other destination. Files are not read for anything but the copy.
- To make the drop zone reachable while the island is a notch or hidden, a low-level mouse hook (`WH_MOUSE_LL`) evaluates only the button state and the cursor position. It runs only while Home Cloud is on and the island is retracted or hidden, and it stores and logs nothing.
- Logs (`%LOCALAPPDATA%\DeveloperIsland\logs`) contain app events and error types, never content, repository names, task titles, event titles or calendar links. For Home Cloud they hold only the number of files, bytes, duration, status and the type of an exception, never file names, folder names, paths or contents. They are kept for 7 days.
- The API equivalent uses a static price catalog and exchange rate. You can adjust both in `%LOCALAPPDATA%\DeveloperIsland\pricing.json`, for example:

  ```json
  { "usdToEur": 0.86, "models": { "your-model-id": { "input": 2.0, "output": 8.0 } } }
  ```

  These are illustrative values, not a current price quote. Prices are USD per million tokens and load on startup.
